# 淡蘭走訪紀錄

淡蘭古道（北路 8、中路 18、南路 14 條）＋宜蘭淡蘭平原線（7 條）＋臺北淡蘭文化徑（7 條），共 54 條路線、184 個打卡地標的手機打卡 App。

- 路線資料來源：淡蘭國家綠道主題網站（danlantrail.necoast-nsa.gov.tw），2026-11-01 擷取
- 地標：官方的起點、迄點，加上 GPX 中有命名的沿途地標。間隔超過 3 km 的地方自動補「途中點」
- 完成率：每條路線的完成度 = 已打卡地標 ÷ 地標數；總完成率依官方里程加權

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html`、`app.js`、`style.css` | 打卡 App |
| `sw.js`、`manifest.webmanifest`、`icons/` | 離線功能、加到主畫面 |
| `data/trails.json` | 路線、地標、軌跡資料 |
| `dashboard.html` | 給 Google Sites 嵌入的唯讀進度看板 |
| `gas/Code.gs` | Google Apps Script 後端（不用上傳到 GitHub） |

## 設定步驟

### 1. 上傳到 GitHub Pages

1. GitHub → New repository，名稱填 `danlan-trail`，選 **Public**，建立
2. 在 repo 頁面按 **Add file → Upload files**，把這個資料夾裡的檔案拖進去（`gas/` 可以不傳）。資料夾 `data/` 與 `icons/` 要連同資料夾一起拖
3. Settings → Pages → Source 選 **Deploy from a branch**，Branch 選 `main` / `(root)` → Save
4. 一兩分鐘後網址會是 `https://你的帳號.github.io/danlan-trail/`

### 2. 設定 Google 試算表與 GAS

1. 打開試算表「淡蘭古道走訪紀錄」→ 擴充功能 → Apps Script
2. 刪掉預設內容，貼上 `gas/Code.gs` 全部內容
3. 把最上方的 `APP_URL` 改成第 1 步的網址（結尾要有 `/`），儲存
4. 上方函式選 `setup` → 執行 → 依指示授權
   - 會自動匯入「路段」「地標」兩張表，並建立「打卡紀錄」「進度」
   - 執行記錄會顯示**通行碼**，記下來
5. 部署 → 新增部署作業 → 齒輪選「網頁應用程式」
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 部署後複製「網頁應用程式網址」（結尾是 `/exec`）

> 之後如果修改 Code.gs，要到「部署 → 管理部署作業 → 編輯 → 版本選新版本」，網址才會套用新程式碼。

### 3. 手機安裝 App

1. 手機開啟 `https://你的帳號.github.io/danlan-trail/`
2. 右上角 ⚙︎ 設定 → 貼上 GAS 網址與通行碼 → 「儲存並測試連線」
3. 加到主畫面
   - iPhone：Safari → 分享 → 加入主畫面
   - Android：Chrome 選單 → 安裝應用程式 / 加到主畫面
4. 第一次開啟時允許「使用位置」

小技巧：也可以直接開 `https://你的帳號.github.io/danlan-trail/?api=GAS網址&token=通行碼`，一次帶入設定。

### 4. Google Sites 進度看板

在 Google Sites → 插入 → 嵌入 → 「依網址」，貼上：

```
https://你的帳號.github.io/danlan-trail/dashboard.html?api=GAS網址
```

看板只顯示完成的地標與進度，不含心得與座標，也不需要通行碼。如果不想公開，可以把 `Code.gs` 裡的 `PUBLIC_SUMMARY` 改成 `false`，看板就讀不到資料了。

## 使用方式

- **現場打卡**：按「📍 在此打卡」。在地標 150 m 內（加上 GPS 誤差）會自動打卡 ✅；不在範圍內會列出附近地標讓你選，並標成 ⚠️ 位置偏差
- **補登**：底部「➕ 補登」，選路線、路段，勾選走過的地標，填日期
- **沒有訊號**：照常打卡，資料存在手機，恢復網路或重新開啟 App 時自動上傳（頂部會顯示待傳筆數）
- **修改地標**：直接改試算表「地標」表的名稱、座標、判定半徑，App 同步後就會套用。地標 ID 不要改

## 資料備註

官網資料本身有幾個問題，處理方式記在「路段」表的「資料備註」欄：

- **官網起迄座標對調已修正**：官網把起點和迄點的座標放反，已用相鄰路段的同名地點校正
- **GPX 不完整**：官方 GPX 只涵蓋部分路段，所以只放起點、迄點，地圖上的軌跡也不完整（嶐嶺、暖東峽谷、上內平林、中坑、北勢溪、烏山越嶺、跑馬、文化徑南路）
- **無 GPX**：四分子古道沒有官方 GPX
- **以 GPX 端點代替**：官網座標和 GPX 端點差距超過 400 m，改採 GPX 端點
- 「途中點」是依 GPX 距離推算的位置，不是實際地標，可以到試算表改成你走過時看到的地標名稱
